# Amazon Clone 🛒

A beginner-friendly Amazon homepage clone built using **HTML and CSS**.

## 📌 About the Project

This project is a frontend clone of the Amazon homepage created to practice and understand the fundamentals of **HTML and CSS**.

The project focuses on recreating the basic structure, layout, styling, navigation, product sections, and footer of an Amazon-style webpage.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome

## ✨ Features

- Amazon-style navigation bar
- Location and delivery section
- Search bar with category selector
- Sign-in and account section
- Returns & Orders section
- Shopping cart
- Secondary navigation panel
- Hero section
- Product/category cards
- Footer section
- Hover effects
